# Lubist — customer app

The customer app for Lubist on Google Play (`com.lubist.mobile`): find salons, book
services, apply coupons, pay, manage bookings, save salons and products.

- **Stack:** Expo SDK 54, React Native, TypeScript, React Navigation, TanStack Query
- **Backend:** the shared FastAPI backend (`g:\vescavia\Projects\backend`)
- **Vendors are not here.** Salon owners use the separate **Lubist Partner** app
  (`lubist_vendor_application`); regular buyers use the website. Both are refused at this
  app's login.

## Running it

```bash
npm install
npm start            # 'a' for Android, or scan the QR in Expo Go
npm run typecheck
```

`.env` points the app at a backend (`EXPO_PUBLIC_API_URL`); copy `.env.example`. Store and
preview builds get their backend URL from `eas.json`, baked in at build time.

## Code map

```
src/
  app/          providers, config (env)
  navigation/   RootNavigator → Auth / Client stacks (+ placeholder Admin, RM home screens)
  features/     auth/, client/ (all customer screens), careers/, admin/, rm/
  services/
    api/        client.ts, hooks/ (one TanStack hook file per resource),
                generated/schema.d.ts (from the backend contract — never edit), types.ts
    appGate/    force-update + wrong-app redirect gate
    location/   notifications/ (stub — push not built)   storage/   upload/
  shared/  store/  theme/  assets/
```

## API types

```bash
npm run api:types    # regenerate src/services/api/generated/schema.d.ts from backend/openapi/openapi.json
npm run api:check    # CI-style: fail if the generated file is stale
```
